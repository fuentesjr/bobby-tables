# Bobby Tables — Class Dismissed

An illustrated, interactive lesson in SQL injection and safer queries.

**Site:** https://fuentesjr.github.io/bobby-tables/

## Development

Static HTML, CSS, and JavaScript; no build step or dependencies. Open `index.html` in a browser.

The enrollment demo is a browser-only teaching simulation. No SQL is executed and no input is sent or saved. It contrasts concatenation with parameterized queries and includes Ruby/PostgreSQL and Rails examples.

## Deployment

GitHub Pages publishes the root of `main`. Changes pushed to `main` deploy automatically. `.nojekyll` keeps the files as plain static assets.
